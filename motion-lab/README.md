# POUND4PADEL - варианты движения

Изолированные демонстрационные страницы. Основной сайт не изменён.
Основа: опубликованная ветка codex/visual-concept, commit 33f0ab5.

- index.html - сравнение и объяснение референсов.
- character.html - текущая фотография и текст, Lenis и раскрытие фото клуба через ScrollTrigger.
- serve.html - существующие фотографии мячей, однократный отскок через GSAP, повтор по кнопке.
- equipment.html - исходная ракетка, переключение цвета формы, Vanta NET на компьютере.

Сохраняются Oswald, Manrope, палитра, логотип, реальные фотографии и рабочие назначения ссылок основного сайта. Никакой новой системы бронирования не добавлено. Варианты не означают одобрение редизайна пользователем.

## Библиотеки

Локальные фиксированные версии: GSAP 3.15.0 + ScrollTrigger, Lenis 1.3.27, Vanta 0.5.24, Three.js 0.134.0. Lenis синхронизирован с GSAP через один ticker. Three.js соответствует r134 из примера README Vanta. Three.js и Vanta загружаются только для варианта equipment при ширине от 901px и точном указателе. Использование WebGL без поддержки даёт статичный фон.

- https://github.com/darkroomengineering/lenis (MIT)
- https://github.com/greensock/GSAP (https://gsap.com/standard-license/)
- https://github.com/tengbao/vanta (MIT)
- https://github.com/mrdoob/three.js (MIT)

При reduced motion анимация и Lenis отключены. Переключение настройки во время просмотра очищает GSAP и WebGL. Vanta уничтожается при уходе со страницы, скрытии вкладки и переходе на мобильный размер. Содержимое доступно без JS.

## Референсы и границы проверки

В браузере просмотрены MotionSites, Navbar Gallery, CTA Gallery, открытая подборка Motion на 60fps. Снимки сохранены вне публикации в output/playwright/ref-*.png. Просмотр превью не означает изучение скрытого исходного кода или закрытых шаблонов.

MotionSites: Outfit Carousel / Runway Lookbook - предметная композиция и выбор варианта. Navbar Gallery: Supaste - компактная навигация с заметным главным действием. Галерея 60fps использована как ориентир для согласованного движения, без копирования конкретного закрытого ролика. CTA Gallery не дала нужного для этой задачи паттерна; подписки и попапы не добавлены. Footer Design, 404s, Unsection и BentoGrids в этой реализации не использовались. Инструмент «Астра» недоступен в текущем наборе.

## Проверки

Проверены рендеры трёх вариантов на 1440px и 390px, страница сравнения на 1440/768/390px. Проверены отсутствие переполнения и сломанных изображений, загрузка Oswald, Lenis на desktop и его уничтожение переключателем, WebGL только на desktop, переключение цвета формы, загрузка всех трёх вариантов с reduced motion. Ошибок pageerror нет. Независимый просмотр восьми кадров: ship для показа экспериментов; это не одобрение пользователя и не оценка кадровой частоты.

Автоматический taste-инспектор для character подтвердил размеры и загрузку шрифтов; мелкие мобильные подписи увеличены до 13px. Его требования четырёх фотографий, восьми движущихся элементов и видео намеренно не применены к ограниченному демонстрационному фрагменту: запросу соответствует одна сцена и продолжение, а не полный сайт с дополнительными эффектами. Кремовый цвет сохранён из принятого бренда. Это исключения по пользовательскому объёму, а не полный проход универсального инспектора.
