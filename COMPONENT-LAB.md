# POUND4PADEL: варианты компонентов

Страница `component-lab.html` содержит три независимых варианта в существующем стиле сайта. Выбор здесь не означает утверждение нового оформления для остальных страниц.

- `?style=club`: спокойные кнопки с заливкой, фотография и панель формата рядом, подписи альбомов под изображениями.
- `?style=sport`: срезанные углы кнопок, формат поверх полноширинной фотографии, открытые подписи альбомов, компактный FAQ.
- `?style=rally`: круглый акцент-мяч с откликом, скруглённые переключатели, подписи внутри фотографий.

Все варианты используют Oswald 500, Manrope, существующие navy/cream/lime цвета и локальные фотографии. Новые файлы не изменяют общие стили сайта. SVG-иконки корта, ракетки, мяча, альбома и календаря имеют одинаковую толщину штриха. Стрелки не используются.

Функции: доступные табы с клавиатурой, раскрытие ответов, отдельные альбомы, нативный dialog с возвратом фокуса, листание кнопками/клавиатурой/горизонтальным свайпом, обработка ошибки изображения и повтор, сохранение выбора в localStorage с обработкой отказа, явная демонстрация загрузки, однократное появление секций, повтор анимации. Поддерживаются системное reduced-motion и ручное отключение движения. Ссылки на запись ведут к реальной странице формата; новый сервис бронирования не создавался.

Движение: press 160 мс; состояние 180-250 мс; появление при скролле 500 мс; демонстрационный повтор 600 мс. CSS и Web Animations API, без новых зависимостей. Используется существующий ease-out cubic-bezier(.23,1,.32,1).

Проверка в Chromium: 1440, 768 и 390 пикселей; загрузка шрифтов, отсутствие горизонтального переполнения, табы, FAQ, изоляция альбомов, возврат фокуса, ожидание загрузки, reduced-motion. UX-проверка отдельно просмотрела снимки всех вариантов, после чего исправлен внутренний фокус срезанных кнопок.
